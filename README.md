# TVBox 定制增强版 (电视大屏端 + 移动手机端)

基于 TVBox 开源项目二次深度定制的高性能多媒体播放器。支持全架构（32位电视盒子 + 64位智能手机）、自适应多分辨率图标套件、服务端统一鉴权的私密频道隐私保护套件、以及 AES-128 端到端加密防抓包防盗链系统。

---

## 📺 核心特性

- 📱 **双架构覆盖**：
  - **电视端（armeabi-v7a / 32位 ARM）**：深度适配主流智能电视、电视机顶盒（如 Model-X3、外贸盒子等）。
  - **手机端（arm64-v8a / 64位 ARM）**：深度适配现代主流安卓手机与平板设备。
- 🎨 **全新自适应图标套件**：
  - 适配 Android 8.0+ (API 26+) Adaptive Icon 标准（432x432 矢量安全区画布），适配圆形、方圆形（Squircle）、圆角矩形遮罩，永不裁切。
  - 专为 Android TV Leanback 大屏定制的 16:9 深邃夜空流光横幅（`app_banner.png`）。
- 🔒 **无痕暗门与双模云端授权套件（1+2+3 组合安全体系）**：
  - 平时彻底无痕，无任何私密字样；
  - 遥控器连击暗门呼出；
  - 手机微信/浏览器扫码免输密码一键解锁 + 遥控器数字 PIN 键盘双模式；
  - 服务端统一管控密码与发放时效 Session Token，退出应用即刻自动上锁。
- 🛡️ **AES-128-CBC 端到端加密流**：
  - 私密频道的真实直连流地址全程密文传输，拦截抓包与嗅探盗刷。

## 🔑 私密频道授权与使用完整说明

为了彻底保护家庭客厅大屏的私密安全，防止家人或小孩误看，同时免去电视遥控器输入繁琐密码的痛点，本项目采用了 **无痕伪装 + 云端双模授权 + 退出即锁** 的完整安全闭环：

### 1. 默认状态（纯净无痕）
- 正常打开软件进入「设置 -> 界面/模式设置」或打开频道列表，**绝无任何私密频道、成人分类或相关开关选项**，如同一个纯净健康的标准播放器，他人借用电视毫无破绽。

### 2. 唤醒隐蔽暗门
1. 用电视遥控器打开 **「设置」 -> 「界面/模式设置」**；
2. 滑动到设置页面的最底部，找到 **「关于软件」** 这一栏；
3. **用电视遥控器连续按 5 次 OK 确认键**（2.5 秒内连续 5 连击，触屏设备可直接连击 5 次）；
4. 屏幕随即呼出 **「🔒 私密安全鉴权」** 交互面板。

### 3. 双模极速解锁（二选一）

| 解锁方式 | 适用场景 | 操作步骤 |
| :--- | :--- | :--- |
| **方式 A：手机扫码秒级授权（强烈推荐）** | 嫌电视按键麻烦、有手机在身边 | 1. 鉴权面板右侧展示动态安全二维码；<br>2. 拿手机打开微信或手机浏览器扫码；<br>3. 手机端打开专属授权页面，输入管理密码（默认：`258258`）；<br>4. 手机点击「立即授权电视端」；<br>5. **电视大屏即刻自动识别并解锁关闭弹窗，全程无需遥控器打字**。 |
| **方式 B：电视遥控器直接输入** | 手机不在身边 | 在鉴权面板左侧输入框输入管理密码，光标移动到下方点击「验证并解锁」即可。 |

### 4. 自动重锁与安全策略
1. **退出应用即刻自动上锁**：
   - 鉴权生成的临时 Session Token **纯内存驻留，绝不写入本地磁盘**；
   - 当按返回键退出应用（或系统杀死进程、电视关机待机）时，Token 瞬间从内存抹除；
   - 下次任何人打开电视，依然是 100% 纯净无痕状态，必须重新通过暗门授权。
2. **手动一键即刻重新隐匿**：
   - 处于解锁状态时，设置界面中会显现「私密频道（已开启，点击即锁定）」；
   - 随时点击该项，私密频道瞬间锁上，入口立即重新隐匿消失。
3. **服务端动态管控密码**：
   - 密码完全受控于您的云端 VPS（可在 `/opt/tvbox-live-hub/data/secret.txt` 或环境变量中修改）；
   - 一旦在服务器修改密码，所有已在线设备的旧 Token **全部瞬间失效**，无需重新编译 APK 即可实现云端权限吊销。

## 📦 APK 编译与安装

项目已配置 GitHub Actions 自动化编译流程，每次提交更新代码后会自动构建 Release 软件包：

1. 进入当前仓库的 **[Releases 页面](../../releases)**；
2. 根据您的设备选择下载：
   - **智能电视/外贸盒子（推荐）**：`TVBox_release-armeabi-generic-python.apk`
   - **现代安卓手机/平板（推荐）**：`TVBox_release-arm64-generic-python.apk`
   - **轻量无 Python 纯 Java 版**：`TVBox_release-*-generic-java.apk`
